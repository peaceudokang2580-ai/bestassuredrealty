# Best Assured Realty

A premium luxury real estate marketplace built with Next.js, TypeScript, and Tailwind CSS.

## Features

- 🏠 Property Listings - Browse luxury properties across Nigeria
- 🔍 Advanced Search - Filter properties by location, type, and more
- 🗺️ Interactive Map - Explore properties on an interactive map (coming soon)
- 💎 Luxury Design - Modern dark theme with gold accents
- 📱 Fully Responsive - Works seamlessly on all devices
- ⚡ Fast Performance - Built with Next.js for optimal speed

## Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
git clone https://github.com/peaceudokang2580-ai/bestassuredrealty.git
cd bestassuredrealty
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Pages

- Home (/) - Landing page with hero section and stats
- Properties (/properties) - Browse and filter properties
- Map (/map) - Interactive property map (placeholder)

## Tech Stack

- Framework: Next.js 14
- Language: TypeScript
- Styling: Tailwind CSS
- Icons: Lucide React
